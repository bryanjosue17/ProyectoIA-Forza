# Prompt: Diseño de entidades de dominio

## Contexto
Sistema PeoplePortal, portal de autoservicio para colaboradores.
Se necesitan entidades para: empleados, documentos, solicitudes, comunicados, beneficios.

## Prompt usado
"Diseña entidades de dominio para un sistema de portal de empleados con Clean Architecture.
Incluye Employee, Document, HrRequest, Announcement, Benefit.
Cada entidad debe tener factory methods, private setters, y métodos de comportamiento.
Usa snake_case para base de datos."

## Resultado
5 entidades creadas en PeoplePortal.Domain/Entities/
