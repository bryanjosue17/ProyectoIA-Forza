## Contenido del video

El video demuestra el flujo completo del sistema PeoplePortal en funcionamiento local:

1. **Despliegue** — Ejecución del script `deploy.ps1` y verificación de pods en Kubernetes
2. **Autenticación** — Login como colaborador y como administrador RRHH via Keycloak
3. **Portal Colaborador** — Dashboard KPIs, documentos, beneficios y solicitudes
4. **Panel RRHH** — Gestión de colaboradores, aprobación de solicitudes, comunicados y beneficios
5. **CI/CD** — Pipeline GitHub Actions con build, tests, análisis de seguridad y push a GHCR
