# PeoplePortal: Portal del Colaborador

## Descripción general

**PeoplePortal** es una plataforma web de autoservicio para colaboradores, diseñada para centralizar la información laboral de cada empleado y facilitar la gestión de procesos internos con RRHH.

El sistema permite que cada colaborador tenga acceso a su propio portal para consultar su información personal, documentos, beneficios, comunicados y realizar solicitudes a RRHH desde un solo lugar.

RRHH, por su parte, cuenta con un panel administrativo para gestionar colaboradores, documentos, solicitudes, aprobaciones, comunicados y reportes.

---

## Problema que resuelve

En muchas empresas, los procesos de RRHH se gestionan de forma manual mediante correos, mensajes, hojas de Excel o documentos dispersos.

Esto genera:

- Pérdida de información.
- Retrasos en solicitudes.
- Falta de seguimiento.
- Dependencia directa de RRHH.
- Documentos desorganizados.
- Dificultad para consultar información laboral.
- Falta de trazabilidad en vacaciones, vouchers y constancias.

Con **PeoplePortal**, el colaborador puede gestionar sus solicitudes de forma autónoma y RRHH puede centralizar toda la información en una sola plataforma.

---

## Objetivo del sistema

Crear una plataforma interna donde los colaboradores puedan acceder a su información laboral, consultar documentos, revisar beneficios, recibir comunicados y realizar solicitudes a RRHH, permitiendo a la empresa digitalizar procesos internos y mejorar la experiencia del colaborador.

# Módulos principales

## 1. Mi perfil

El colaborador puede consultar su información laboral y personal registrada en la empresa.

Incluye:

- Nombre completo.
- Código de empleado.
- Puesto.
- Departamento.
- Jefe inmediato.
- Fecha de ingreso.
- Tipo de contrato.
- Estado laboral.
- Correo corporativo.
- Teléfono.
- Contacto de emergencia.
- Sede o modalidad de trabajo.

También puede solicitar actualización de datos personales desde el módulo de **Solicitudes a RRHH**.

---

## 2. Mis documentos

Repositorio digital personal del colaborador.

Puede incluir:

- Contrato laboral.
- DPI o identificación.
- Constancias laborales.
- Cartas emitidas.
- Certificados.
- Documentos firmados.
- Políticas aceptadas.
- Formularios internos.
- Documentos relacionados con beneficios.
- Documentos generados por RRHH.

Estados posibles:

- Disponible.
- Pendiente.
- En revisión.
- Aprobado.
- Rechazado.
- Vencido.

---

## 3. Comunicados internos

Espacio donde la empresa puede publicar avisos importantes para los colaboradores.

Puede incluir:

- Noticias internas.
- Avisos de RRHH.
- Cambios de políticas.
- Eventos internos.
- Recordatorios.
- Fechas importantes.
- Cumpleaños laborales.
- Anuncios institucionales.

---

## 4. Beneficios

Sección informativa donde el colaborador puede consultar los beneficios disponibles dentro de la empresa.

Puede incluir:

- Seguro médico.
- Bonificaciones.
- Convenios.
- Descuentos.
- Programas internos.
- Políticas de vacaciones.
- Políticas de permisos.
- Programas de bienestar.
- Beneficios por antigüedad.

---

## 5. Dashboard del colaborador

Pantalla principal donde el colaborador ve un resumen de su información y gestiones.

Puede mostrar:

- Bienvenida personalizada.
- Información básica del colaborador.
- Solicitudes recientes.
- Estado de vacaciones solicitadas.
- Últimos documentos disponibles.
- Comunicados importantes.
- Beneficios destacados.
- Notificaciones pendientes.

---

## 6. Solicitudes a RRHH

Este es uno de los módulos principales del sistema. Centraliza todas las gestiones que el colaborador puede realizar hacia RRHH.

### Tipos de solicitudes

#### Solicitud de vacaciones

El colaborador puede solicitar vacaciones desde el portal.

Incluye:

- Fecha de inicio.
- Fecha de fin.
- Cantidad de días solicitados.
- Comentario opcional.
- Estado de aprobación.
- Responsable o aprobador asignado.
- Historial de solicitudes.

Estados posibles:

- Solicitada.
- En revisión.
- Aprobada.
- Rechazada.
- Cancelada.

---

#### Solicitud de vouchers de pago

El colaborador puede solicitar un voucher o comprobante de pago cuando lo necesite.

Incluye:

- Período solicitado.
- Motivo de solicitud.
- Estado de la solicitud.
- Archivo PDF disponible para descarga cuando RRHH o nómina lo cargue.

Estados posibles:

- Solicitado.
- En proceso.
- Disponible para descarga.
- Rechazado.
- Finalizado.

---

#### Solicitud de constancias

El colaborador puede solicitar documentos laborales como:

- Constancia laboral.
- Carta salarial.
- Carta de ingresos.
- Carta para trámite bancario.
- Carta para visa.
- Certificación de empleo.

Incluye:

- Tipo de constancia.
- Motivo de solicitud.
- Institución a la que va dirigida, si aplica.
- Comentarios.
- Documento generado para descargar.

Estados posibles:

- Solicitada.
- En revisión.
- En proceso.
- Lista para descargar.
- Rechazada.
- Finalizada.

---

#### Otras solicitudes a RRHH

También puede incluir:

- Solicitud de permisos.
- Actualización de datos personales.
- Consulta de beneficios.
- Solicitud de documentos internos.
- Reportes o consultas administrativas.
- Seguimiento de casos abiertos.

Cada solicitud tendría:

- Tipo de solicitud.
- Fecha de creación.
- Estado.
- Responsable asignado.
- Comentarios.
- Archivos adjuntos.
- Documento generado para descargar, cuando aplique.

---

## 7. Panel administrativo RRHH

RRHH cuenta con un panel para administrar toda la información del sistema.

Funciones principales:

- Crear colaboradores.
- Editar información laboral.
- Administrar usuarios.
- Gestionar roles y permisos.
- Subir documentos.
- Gestionar solicitudes.
- Aprobar o rechazar vacaciones.
- Cargar vouchers de pago.
- Generar o cargar constancias.
- Publicar comunicados.
- Administrar beneficios.
- Revisar historial por colaborador.
- Consultar reportes.

---

## 8. Reportes

El sistema puede generar reportes para RRHH y administración.

Reportes sugeridos:

- Solicitudes pendientes.
- Solicitudes por tipo.
- Solicitudes por estado.
- Vacaciones solicitadas.
- Vouchers solicitados.
- Constancias generadas.
- Documentos pendientes o vencidos.
- Colaboradores activos.
- Historial de gestiones por colaborador.

## Estructura Monorepo y submódulos

Este repositorio actúa como un monorepo que referencia tres repositorios independientes mediante submódulos Git:

- `PeoplePortal-BackEnd` (rama de trabajo: `develop`)
- `PeoplePortal-FrontEnd-Colaborador` (rama de trabajo: `develop`)
- `PeoplePortal-FrontEnd-RRHH` (rama de trabajo: `develop`)

Recomendación de ramas:

- `main`: rama por defecto (estable)
- `develop`: rama de trabajo donde se integran cambios antes de pasarlos a `main`

Clonar este monorepo (incluyendo submódulos):

1) Clonar con submódulos recursivos:

```bash
git clone --recurse-submodules https://github.com/bryanjosue17/ProyectoIA-Forza.git
```

2) Si ya clonaste sin submódulos, inicializarlos y actualizarlos:

```bash
git submodule update --init --recursive
```

Actualizar submódulos a la última rama `develop` remota:

```bash
# Desde la raíz del monorepo
git submodule foreach 'git fetch origin && git checkout develop && git pull origin develop'
```

Trabajar en submódulos (flujo sugerido):

1. Entrar en el submódulo correspondiente:

```bash
cd PeoplePortal-BackEnd
# o PeoplePortal-FrontEnd-Colaborador, PeoplePortal-FrontEnd-RRHH
```

2. Crear/usar la rama `develop` localmente, realizar cambios y pushear:

```bash
git checkout develop
git pull origin develop
# hacer cambios
git add .
git commit -m "Describe cambios"
git push origin develop
```

3. Volver al monorepo y commitear la referencia del submódulo (si cambiaste commit dentro del submódulo):

```bash
cd ..
git add PeoplePortal-BackEnd PeoplePortal-FrontEnd-Colaborador PeoplePortal-FrontEnd-RRHH
git commit -m "Update submodule refs"
git push origin develop
```

Notas:

- Los submódulos mantienen su historial en sus propios repositorios.
- Para clonar y colaborar cómodamente, usa `--recurse-submodules` o ejecuta `git submodule update --init --recursive` tras clonar.
- Si prefieres no usar submódulos, considera `git subtree` o un monorepo con fusión de historiales.
